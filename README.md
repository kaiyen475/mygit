# VITALL 탐사 게시판

생태연구회 VITALL의 탐사 공지·신청 웹사이트입니다. 사이트 소스와 자동 배포 설정을 제공합니다.

## 실제 사이트

**https://vitall-field-notes.ki955725.workers.dev/**

https://kaiyen475.github.io/mygit/ 에 접속해도 실제 사이트로 이동합니다. 회원가입 없이 탐사에 신청하고, 관리자 비밀번호를 입력하면 공지를 작성하고 신청자 전체 정보를 확인할 수 있습니다.

운영자는 처음 표시되는 예시를 수정하거나 실제 탐사를 새로 등록해 신청을 받습니다. 예시에는 신청할 수 없습니다.

## 실제 신청 기능 배포

Cloudflare Worker와 D1의 배포가 완료되었습니다. 이후 main에 변경 사항을 올리면 데이터베이스를 유지하면서 자동으로 업데이트합니다. 다른 계정에서 처음 배포할 때의 설정 방법은 [DEPLOY.md](DEPLOY.md)에 있습니다. 운영자 비밀번호는 서버의 비밀 값으로 관리하며, 신청 정보는 공용 D1 데이터베이스에 저장합니다.

- 누구나 회원가입 없이 신청
- 이름, 전화번호, 쌍안경·장화 대여, 집합 장소, 탐사 후 식사 여부, 하고 싶은 말(선택)
- 카테고리별 게시판 및 지난 탐사 조회
- 공개 화면에는 신청자 이름과 인원만 표시
- 운영자 비밀번호 인증 후 공지 작성·수정·삭제, 전체 신청 정보·준비 합계·CSV 확인
- 공지에 사진 최대 5장 등록·교체·삭제, 큰 사진은 브라우저에서 자동 축소(저장 시 장당 최대 1MiB)
- 전화번호와 하고 싶은 말을 포함한 신청 상세 정보는 운영자만 확인
- 서버에서 마감·정원·중복 신청·개인정보 공개 범위 검사

사진은 공지와 함께 공개됩니다. JPG·PNG·WebP를 지원하며, 게시물을 삭제하면 해당 신청 정보와 사진도 함께 삭제됩니다. 삭제 전 확인 창을 표시합니다.

처음 표시되는 탐사는 예시입니다. 운영자가 실제 탐사를 등록하면 신청을 받습니다. 운영자 비밀번호와 실제 신청자 정보는 저장소에 포함되지 않습니다.

## 개발·검증

Node 24 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
node --no-warnings scripts/verify-free.mjs
node --no-warnings build-free.mjs
```

로컬 실행은 Python 3.10 이상에서 `python3 server.py --open`을 사용합니다. 시작할 때 운영자 비밀번호를 설정하며, 신청 정보는 로컬 `.vitall-data/vitall.db`에 저장됩니다.
